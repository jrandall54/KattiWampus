# kattiswauler

Repository of Kattis-style programming problems and reference solutions.

Contents:
- `problem.md` — main problem (Rotate Points).
- `variants/` — alternate problem variants exploring matrix multiplication and rotations.
- `matrix.java` — reference solution placeholder (Java).
- `tests/` — sample input/output cases and test harness.

Getting started

1. Build and run Java solutions:

```bash
javac matrix.java
java Matrix < input.txt
```

2. Run tests (if provided):

```bash
./scripts/run_tests.sh
```
